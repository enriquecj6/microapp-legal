Datos y almacenamiento

La aplicación no recopila datos personales. No trata datos sensibles. Los datos de uso se almacenan únicamente de forma local en el dispositivo; no hay cuenta, backend, analítica ni publicidad.

Acceso, recopilación y compartición

Datos accedidos: información introducida por la persona usuaria para las funciones descritas. Datos recopilados por el desarrollador: ninguno. Datos compartidos: ninguno salvo acción explícita de compartir o exportar.

Servicios de terceros y permisos

Servicios de tratamiento de datos declarados: ninguno. Permisos: ningún permiso sensible.

Retención, borrado y exportación

Hasta que el usuario elimine los datos locales. La persona usuaria puede borrar sus datos desde la aplicación. No hay exportación de datos.

Seguridad

Se aplican las protecciones del almacenamiento local y del sistema operativo. Ningún sistema es infalible; mantenga el dispositivo actualizado y protegido.

Cambios y contacto

Esta política se actualizará si cambia el comportamiento real de la aplicación. Consultas: enriquecj666@gmail.com.
